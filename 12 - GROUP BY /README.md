🗂️ DOMINANDO O GROUP BY NO SQL

Este repositório reúne os exercícios e desafios que desenvolvi para dominar o uso da cláusula GROUP BY no SQL Server. O objetivo foi entender como consolidar dados
e transformar milhares de linhas individuais em resumos inteligentes para o negócio.

🚀 Impacto Real
Com esses exercícios, aprendi a criar relatórios de posicionamento de mercado (como identificar marcas premium vs. marcas populares dentro de uma mesma categoria)
sem gerar tabelas poluídas ou duplicadas.
